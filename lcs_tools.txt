
# Tools that generate an LCS on the command line

## 1. **diff** (GNU diff)
`diff` itself computes an LCS internally (Myers algorithm).  
You can extract the LCS by asking for **common lines only**:

```
diff --unchanged-line-format='%L' --old-line-format='' --new-line-format='' file1 file2
```

This prints the **LCS of lines**, not characters.

If your “strings” are short, you can put each character on its own line:

```
printf "%s" "$s1" | sed 's/./&\n/g' > a
printf "%s" "$s2" | sed 's/./&\n/g' > b
diff --unchanged-line-format='%L' --old-line-format='' --new-line-format='' a b
```

This yields a **character‑level LCS** using only POSIX tools.

---

## 2. **wdiff**  
`wdiff` computes word‑level differences using an LCS internally.

To extract the LCS (common words):

```
wdiff -3 file1 file2
```

`-3` prints only common words.

---

## 3. **patience diff** (via `git diff --patience`)
Patience diff is an LCS variant optimized for readability.  
You can run it on arbitrary files:

```
git diff --no-index --patience a b
```

Not a pure LCS, but extremely close and often better for text animation.

---

## 4. **sdiff**  
`sdiff` shows side‑by‑side alignment, which is literally the LCS alignment.

```
sdiff -s a b
```

The `-s` flag suppresses common lines, but without it you get the aligned LCS.

---

## 5. **[diffutils cmp + diff]**  
`cmp` gives you the first differing byte; combined with `diff` you can reconstruct the LCS.  
Not recommended unless you need byte‑level precision.

---

# Tools that compute LCS directly (not diff-based)

These are **actual CLI tools** that compute LCS explicitly:

## 6. **lcs** (Rust crate with CLI)
If installed:

```
lcs string1 string2
```

Outputs the LCS directly.

---

## 7. **tre-agrep**  
TRE’s approximate matching engine can compute edit distance and alignment.  
Not pure LCS, but you can derive it from the alignment.

---

# The simplest *pure* LCS tool you already have: **diff**

If you want a **pure LCS** and you don’t want to install anything:

### Character-level LCS from two shell strings

```
s1="abcdef"
s2="acdf"

printf "%s" "$s1" | sed 's/./&\n/g' > a
printf "%s" "$s2" | sed 's/./&\n/g' > b

diff --unchanged-line-format='%L' --old-line-format='' --new-line-format='' a b
```

Output:

```
a
c
d
f
```

That is the **LCS**.

---

# Best tool for your animation use case

Use **diff** with per-character lines.  
It is:

- installed everywhere  
- fast  
- stable  
- produces the exact LCS  
- trivial to parse in Bash/Perl
