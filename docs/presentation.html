What is diffvim?

diffvim opens the old version of a file in vim and animates the transformation into the new version character by character. The cursor glides between change locations with smooth ease-in-out acceleration, and only the actually-changed characters are deleted and re-typed — surrounding text is never touched.

It's like watching a senior developer type out a code change in real time, except it's automated, perfectly paced, and you can pause, skip, rewind, and change speed at any moment.

Key features

🎯

Char-level precision

Only the actually-changed characters are touched. No whole-line rewrites. The LCS algorithm finds the minimal edit script.

🌊

Smooth cursor glide

Cursor glides between change locations with ease-in-out cubic acceleration. Slow start, fast middle, slow end — like a human.

⏸️

Full playback control

Pause, skip hunks, go back, change speed (±), undo/redo, step mode. All in real time without restarting.

🔀

3 diff algorithms

LCS (classic), Myers (O(ND)), and Patience (unique-line anchoring). Choose the one that produces the most readable diff.

🌍

UTF-8 aware

Multi-byte characters (em-dash —, ©, emoji) are handled correctly. The cursor tracks byte positions, not character positions.

📝

Vim plugin mode

Run inside an existing vim session via :Diffvim, :DiffvimCommit, and :DiffvimPick commands. No tmux needed.

🎨

Visual highlighting

Highlight hunk regions before animating. Choose colors, duration, and minimum size. Fold unchanged regions. Apply themes.

🔧

Git integration

Replay git history commit-by-commit. Pick commits with fzf preview. Show git blame during animation. Accept piped diffs.

Get started in 30 seconds

⚡ Quick start

Option 1: Homebrew (macOS)

brew install ./packaging/diffvim.rb
diffvim old.py new.py

Option 2: Manual

git clone https://github.com/nkh/gitanim.git
cd gitanim
chmod +x diffvim
./diffvim old.py new.py

Option 3: Vim plugin

" In vimrc with vim-plug:
Plug 'nkh/gitanim', {'rtp': '.'}

" Then in vim:
:Diffvim old.py new.py
:DiffvimCommit HEAD~3
:DiffvimPick

Controls during animation

KeyAction
SpacePause / resume (or advance one op in step mode)
nSkip current hunk — apply instantly, move to next
bBack to previous hunk — revert and restart
qStop animation — leave buffer for editing
+ / -Speed up / slow down (×1.5 per press)
=Reset speed to 1.0×
u / Ctrl-rUndo / redo last hunk
B / NGo back one op / skip to next file
Ctrl-B / Ctrl-NGo to beginning / skip to end

Popular option combinations

# Presentation mode — slow, centered, highlighted
diffvim --speed 0.5 --scroll zz --highlight-hunk --theme high-contrast old.py new.py

# Quick review — fast, skip large hunks, fold unchanged
diffvim --speed 3 --max-hunk-chars 100 --fold-unchanged old.py new.py

# Detailed code review — step through one char at a time
diffvim --step-mode --highlight-hunk --sign-column --scroll zz old.py new.py

# Git replay with fzf commit picker
:DiffvimPick

# Pipe git diff directly
git diff HEAD~1 -- src/main.py | diffvim --diff -

# Multi-file animation
diffvim --multi old1.py:new1.py old2.py:new2.py old3.go:new3.go

# Patience diff with word-level changes
diffvim --algorithm patience --word-diff --semantic-cleanup old.py new.py

Six built-in presets

Skip the option soup — pick a preset and you're done. Each preset bundles a sensible combination of post-processing, timing, and highlighting flags tuned for one common use case.

default
Everyday use
diffvim old.py new.py

Raw LCS with optimize_sequence. No surprises.

fast-delete
Refactors
diffvim --preset fast-delete old.py new.py

Rapid-EOL + accel-delete + word-accel. Burns through long deletion blocks.

review
Code review
diffvim --preset review --git-blame old.py new.py

Step-mode, hunk highlight, dim-unchanged, top-aligned. Press n to advance.

ai-code
AI diffs
diffvim --preset ai-code --tool rust old.py new.py

Semantic cleanup + left-to-right + word-diff. Tames messy AI-generated diffs.

demo
Live demos
diffvim --preset demo old.py new.py

0.7x speed, inline highlight, word pause. For audience-friendly walkthroughs.

presentation
Screencasts
diffvim --preset presentation --output out.py old.py new.py

1.2x speed, no rapid-EOL, centered scroll. For recording smooth video.

Define your own with DIFFVIM_PRESET="review --highlight-word".

Post-processing pipeline

Raw LCS diffs can be confusing — characters deleted here, inserted there, then more deletes elsewhere on the same line. diffvim's post-processing passes reorder ops for human readability.

   raw char_ops
        │
        ▼
   ┌─────────────────┐
   │ semantic_cleanup│  ← merge adjacent del/ins pairs into keeps
   └────────┬────────┘
            ▼
   ┌─────────────────┐
   │ optimize_seq    │  ← within each line, deletes before inserts
   └────────┬────────┘
            ▼
   ┌─────────────────┐
   │ left_to_right   │  ← within each line: keeps, then dels, then ins
   └────────┬────────┘
            ▼
   ┌─────────────────┐
   │ delete_end_first│  ← move trailing deletes to the end of the line
   └────────┬────────┘
            ▼
   ┌─────────────────┐
   │ overwrite       │  ← replace delete+insert with in-place overwrite
   └────────┬────────┘
            ▼
   final char_ops (what the animator consumes)

Each pass is independently toggleable. See docs/POST_PROCESSING.md for the full reference.

External compute tools

For files larger than a few hundred lines, the in-vim LCS can take seconds. The external compute tools solve this — 10-100x faster, implemented in four languages with byte-for-byte identical output.

C
diffvim-compute-c
Reference implementation. Smallest binary, fastest startup.
C++
diffvim-compute-cpp
Modern C++17. Same speed as C.
Rust
diffvim-compute-rust
Same speed as C/C++. Safest to extend.
Go
diffvim-compute-go
Same speed. Best if your team uses Go.
# Build all four variants
make -C compute

# Use the C variant via the wrapper script
diffvim-precomputed old.py new.py

# Pick a specific language
diffvim-precomputed --tool rust --time --semantic-cleanup old.py new.py

# Benchmark on a 1000-line Python file:
  vimscript LCS:        ~3500 ms
  diffvim-compute-c:       11 ms   (318x faster)
  diffvim-compute-rust:    13 ms   (270x faster)
