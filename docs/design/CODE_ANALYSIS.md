## P0 — Broken on first use

These bugs cause scripts to fail immediately. Users will hit them on the first run.

#1 `scripts/ad_demo.sh:48,52,56` — Wrong path to ad_pipeline

References `$ROOT/animator/ad_pipeline` which doesn't exist. The pipeline lives at `pipeline/ad_pipeline`. All three demo commands fail.

Fix: `sed -i 's|animator/ad_pipeline|pipeline/ad_pipeline|g' scripts/ad_demo.sh`

#2 `scripts/ad_package.sh:52,54-56,60-72` — Multiple wrong paths

References `compute/` (now `diff_engine/`), `animator/c/animator.c` (now `animator/c/ad.c`), `diffvim` (now `apps/vim/ad_vim`), `plugin/` (now `apps/vim/plugin.vim`), `DiffVim/` (now `perl/DiffVim/`). The packaging script is completely broken.

Fix: Rewrite all paths to match the new directory structure.

#3 `scripts/ad_compare:96,98` — Wrong binary name and make target

References `bin/ad_compute-c` (actual: `bin/ad_compute`) and `make -C compute` (actual: `make -C diff_engine`).

Fix: `sed -i 's|ad_compute-c|ad_compute|g; s|make -C compute|make -C diff_engine|g' scripts/ad_compare`

#4 `scripts/ad_jogger:227` — Wrong launcher path

References `$SCRIPT_DIR/diffvim` which doesn't exist. The launcher is at `apps/vim/ad_vim`.

Fix: `sed -i 's|$SCRIPT_DIR/diffvim|$SCRIPT_DIR/../apps/vim/ad_vim|g' scripts/ad_jogger`

#5 `pipeline/ad_pipeline:227,231,243,248,252,262` — `$dp_val` is never defined

6 lines use `$dp_val` but this variable is never set anywhere. Should be `$val`. Pipeline crashes on any unprefixed option that takes a value (e.g. `--op-order optimize`).

Fix: `sed -i 's/\$dp_val/\$val/g' pipeline/ad_pipeline`

#6 `pipeline/ad_pipeline:347` — `DECORATE_ARGS=()` declared after parsing loop

`DECORATE_ARGS=()` is declared at line 347, AFTER the parsing loop (lines 135-270) that tries to append to it. Anything pushed during parsing is wiped out.

Fix: Move `DECORATE_ARGS=()` to line 129 with the other array initializations.

#7 `scripts/ad_debug_bundle.sh:137` — Invalid `export` syntax

`export --left-to-right` is invalid bash. `export` doesn't recognize `--left-to-right` as a variable name. With `set -e`, the script may abort here.

Fix: Remove the line (the orchestrator now handles this via `--ad-layer` flags).

## P1 — Silent logic bugs

These produce wrong output without erroring.

#8 `scripts/ad_tune.sh:270-275` — Duplicate `E)` case shadows swap key

The `case` block has `e|E)` (matches both cases) followed by `E)` (unreachable). Pressing `E` edits OLD instead of NEW (the intended swap behavior).

Fix: Change first case to `e)` only, keep `E)` for the swap.

#9 `scripts/ad_tune.sh:277` — `$1` should be `$key`

`if [[ "$1" == "s" ]]` checks the script's first positional arg, not the keystroke. Should be `$key`. The swap never triggers.

Fix: `sed -i 's/\$1 == "s"/\$key == "s"/' scripts/ad_tune.sh`

#10 `scripts/ad_tune.sh:204` — `$bundledir` typo for `$bundle_dir`

`cp "$WORKDIR/timed.txt" "$bundledir/"` — `$bundledir` is undefined. Timed-ops file missing from debug bundles.

Fix: `sed -i 's/\$bundledir/\$bundle_dir/g' scripts/ad_tune.sh`

#11 `scripts/ad_tune.sh:255` — References non-existent script

`bash "$ROOT/scripts/snapshot_per_op.sh"` — file doesn't exist. Should be `ad_snapshot.sh`.

Fix: `sed -i 's|snapshot_per_op.sh|ad_snapshot.sh|g' scripts/ad_tune.sh`

#12 `apps/vim/ad_vim:1393` — Stray debug echo

`echo "DEBUG: "` prints to stdout on every run with the external pipeline.

Fix: Remove the `echo "DEBUG: "` part.

#13 `apps/vim/ad_vim:626` — Dead preset branch

`if [[ -n "" ]]` is always false. The entire `custom)` preset branch is dead code. Also uses `eval` on user input (security risk if fixed).

Fix: Delete the branch or fix the condition to `[[ -n "$AD_PRESET_CUSTOM" ]]`.

#14 `apps/vim/ad_vim:1459,1484` — Self-assignment

`TIMED_OPS="$TIMED_OPS"` is a no-op. Leftover from when there was a decorate-or-fallback branch.

Fix: Delete both lines.

#15 `diff_engine/perl/compute.pl:43-57` — CLI flags silently ignored

`--semantic-cleanup`, `--word-diff`, `--indent-aware` are accepted but the `parse_diff` call hardcodes `semantic_cleanup => 0, indent_aware => 0`.

Fix: Wire the CLI flags through to the options hash, or remove them from the help text.

#16 `diff_engine/cpp/compute.cpp:511-530` — `optimize_sequence` is a no-op

The function walks ops and pushes them one-by-one — output is identical to input. The `--optimize-sequence` flag advertises optimization but delivers nothing.

Fix: Either implement the intended optimization or delete the function and the CLI flags.

#17 `animator/c/ad.c:650-656` — `--seek` is broken

Comment says "apply ops to maintain buffer state, but don't render" but code does `continue;`, which SKIPS applying entirely. After `--seek N`, the buffer is the original file, not the file at op N.

Fix: Call op handlers without `render()` instead of `continue;`.

#18 `animator/c/ad.c:530` — Dead ternary

`viewport_height + (show_progress ? 0 : 0)` — both branches return 0. Likely a typo for `? 1 : 0`.

Fix: Change to `(show_progress ? 1 : 0)`.

#19 `layers/c/ad_layer_highlight.c:352` — Stale `last_changed_line`

If a hunk has no change ops (only keeps), `last_changed_line` retains its value from the previous hunk. Dim/fold ranges drift after change-free hunks.

Fix: Reset `last_changed_line` to 0 at HUNK start.

#20 `layers/c/ad_layer_pace.c:757` — `changed_lines` not incremented for word-pacing \n inserts

In `--insert-pacing word` mode, `\n` inserts do NOT increment `changed_lines`, so `--pause-after-lines` never fires for newline inserts.

Fix: Move the `if (code == 10) changed_lines++` block above the `if (insert_pacing == "word")` branch.

#21 `perl/DiffVim/Parser/Perl.pm:129-231` — Dead Myers diff code

`_myers_diff` and `_myers_backtrace` (~100 lines) are never called. Help text claims Myers is supported.

Fix: Delete the dead code or wire it up.

## P2 — Security and robustness

#22 `animator/perl/colorize.pl:296-299,321` — Command injection via unquoted paths

`system("vim ... $file")` and `qx(pygmentize ... $file)` interpolate unquoted paths. If a filename contains shell metacharacters, arbitrary commands execute.

Fix: Use list-form `system("vim", "-u", "NONE", ..., $file)`.

#23 `apps/vim/ad_vim:630` — `eval` on user input

`eval "$(echo "$1" | tr ...)"` on user-provided option text. Command injection.

Fix: Remove the `eval` or validate input strictly.

#24 `apps/vim/ad_vim.pl:1059-1063` — Unescaped placeholder substitution

Config values are interpolated into vimscript strings without escaping. If a value contains a single quote, the vimscript breaks.

Fix: Escape single quotes before interpolation.

#25 `apps/vim/ad_vim:2127-2170` — Unquoted `$NEW` in vim -c

`-c "let g:diffvim_new_file = '$NEW'"` — if `$NEW` contains a single quote, vimscript breaks.

Fix: Escape single quotes: `${NEW//\'/\'\'}`.

#26 `scripts/ad_debug.sh:130,140,150` — stderr mixed into TSV output

`2>&1` redirects layer stderr into the TSV output file, breaking downstream parsers.

Fix: Use `2>"$OUTDIR/postprocess_stderr.txt"` instead of `2>&1`.

#27 `scripts/ad_record.sh:53` — Fixed temp path

`/tmp/dv_raw.txt` — two users on the same machine clobber each other's files.

Fix: Use `mktemp`.

#28 `scripts/ad_replay.sh:49` — Fixed output path

`/tmp/dv_replay_out.txt` — cannot replay two recordings without overwriting.

Fix: Add `--output FILE` flag.

#29 `animator/c/ad.c:30-36` — Signal handler calls non-async-signal-safe functions

`cleanup_handler` calls `printf`, `fflush`, `tcsetattr`, `exit` — none are async-signal-safe. Undefined behavior per POSIX.

Fix: Only call `write(2, ...)` and `_exit(1)` in the signal handler. Move cleanup to an `atexit` handler.

## P3 — Maintainability

#30 C layer boilerplate duplication (~600 LOC)

The 4 small layer .c files (`reorder`, `overwrite`, `indent_last`, `line_delete_in_place`) each triplicate the hunk-processing code (HUNK-start, HUNK_END, EOF). Combined with cross-file boilerplate, ~60-70% of the layer .c code is duplicated.

`ad_layer_common.h` already provides `ad_layer_run_layer()` to eliminate this, but no layer uses it.

Fix: Refactor the 4 layers to use `ad_layer_run_layer()`, or extract `reorder_hunk()`, `overwrite_hunk()`, etc. helpers.

#31 Perl layer boilerplate (~452 LOC)

7 Perl layer files share byte-for-byte duplicated `parse_op`, `char_repr`, `write_op`, `is_debug_op`, `debug_log`, and the main hunk-driver loop.

Fix: Create `perl/DiffVim/Layer.pm` module exporting shared functions + a `run_layer(\&transform)` driver.

#32 `animator/c/ad.c` — 360-line `main()` and 110-line `render()`

Both far exceed the 100-line guideline.

Fix: Split `main()` into `parse_args()`, `load_inputs()`, `main_loop()`, `cleanup()`. Split `render()` into `compute_scroll_offset()` and `emit_frame()`.

#33 `layers/c/ad_layer_pace.c` — 430-line `main()`

Single function handles 6 pacing strategies in one giant if-else chain.

Fix: Split into `pace_char_delete()`, `pace_rapid_eol()`, `pace_rapid_identical()`, `pace_awd()`, `pace_word_insert()`, etc.

#34 `apps/vim/ad_vim` — 2,170-line monolithic script

Single Bash script with embedded 800-line vimscript heredoc.

Fix: Split into `ad_vim` (CLI parsing), `ad_vim_engine.vim` (animation engine), `ad_vim_pipeline.sh` (pipeline runner).

#35 `scripts/ad_tmux` — 1,673-line script duplicating 60% of ad_vim

Duplicates CLI parsing, vimscript engine, and animation loop from `ad_vim`.

Fix: Make `ad_tmux` a thin wrapper around shared code.

#36 Magic number `1048576` (1MB) defined 4 times

In `ad_layer_common.h`, `ad_layer_pace.c`, `ad_layer_highlight.c`, `animator/c/ad.c`.

#37 TSV tokenizer duplicated 9+ times

`parse_tsv` in `ad_layer_pace.c`, `ad_layer_highlight.c`, inlined twice in `ad.c`, variant in `ad_layer_common.h`.

#38 `char_repr` defined 3 times

#39 Option routing duplicated in 4 scripts

`ad_pipeline`, `ad_snapshot.sh`, `ad_vim`, `ad_tmux` all have ~50-line option-routing `case` blocks.

#40 Dead stubs in `ad_layer_highlight.c`

`do_highlight_word` (line 244) and `git_blame` (line 388) are stubs that don't do what they claim.

## C/C++ specific issues

#42 Realloc anti-pattern (7 occurrences)

In `ad_layer_common.h:444,457,472`, `ad_layer_reorder.c:98`, `ad_layer_overwrite.c:38`, `ad_layer_indent_last.c:77`, `ad_layer_line_delete_in_place.c:73`, `ad_layer_pace.c:413`, `ad_layer_highlight.c:70`, `animator/c/ad.c:199,354,422,633`.

Pattern: `ptr = realloc(ptr, new_size);` — on failure, original pointer is leaked AND becomes NULL.

Fix: `Op *tmp = realloc(ptr, new_size); if (tmp) ptr = tmp; else { /* handle */ }`

#43 Missing NULL checks on malloc (20+ occurrences)

Every `malloc`/`realloc`/`strdup` in the C code lacks a NULL check. On OOM, the code segfaults.

Fix: Add `if (!ptr) { fprintf(stderr, "out of memory\n"); exit(1); }` after every allocation.

#44 Non-reentrant `char_repr` (`ad_layer_common.h:127`)

`static char buf[8];` — two calls in the same expression clobber each other.

Fix: Pass a buffer argument.

#45 `optimize_sequence` in compute.cpp is a no-op (lines 511-530)

Walks ops and pushes them one-by-one — output is identical to input.

Fix: Implement the intended optimization or delete the function.

#46 `patience_diff_range` has no depth limit (compute.cpp:280)

Recursive without depth limit. Adversarial inputs could stack-overflow.

Fix: Add `if (depth > 64) { /* fall back to LCS */ }` like `anchored_diff` does.

#47 `find_patience_anchors` is O(n²·m) (compute.cpp:217)

For each line in `a`, counts occurrences in `a` (O(n)) AND in `b` (O(m)).

Fix: Pre-compute with hash maps.
