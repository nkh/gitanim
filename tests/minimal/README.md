# tests/minimal/

25 minimal old/new file pairs, each testing ONE specific transformation.
Designed for debugging — when something breaks, these cases help you
isolate which transformation is wrong.

## Quick start

```bash
# Generate the test cases (creates old and new files):
bash tests/generate_minimal_tests.sh

# Run all minimal tests:
bash tests/run_minimal_tests.sh

# Run one minimal test:
bash tests/run_minimal_tests.sh 11_delete_last_line

# Debug one case with the full pipeline debugger:
bash scripts/dv_debug.sh tests/minimal/11_delete_last_line/old \
                          tests/minimal/11_delete_last_line/new

# Visualize every op as HTML:
bash scripts/dv_dv_snapshot_per_op.sh tests/minimal/15_join_two_lines/old \
                               tests/minimal/15_join_two_lines/new
```

## Test cases

| # | Directory | What it tests |
|---|-----------|---------------|
| 01 | `01_simple_replace` | One char replaced mid-line |
| 02 | `02_simple_insert` | One char inserted mid-line |
| 03 | `03_simple_delete` | One char deleted mid-line |
| 04 | `04_word_replace` | A whole word replaced |
| 05 | `05_delete_to_eol` | Delete from cursor to end of line |
| 06 | `06_insert_at_eol` | Insert at end of line |
| 07 | `07_insert_at_bol` | Insert at beginning of line |
| 08 | `08_line_replace` | One line completely replaced |
| 09 | `09_delete_middle_line` | A middle line removed |
| 10 | `10_delete_first_line` | The first line removed |
| 11 | `11_delete_last_line` | The last line removed (tricky) |
| 12 | `12_insert_line_at_end` | A new line appended at EOF |
| 13 | `13_insert_line_at_start` | A new line inserted at top |
| 14 | `14_insert_line_in_middle` | A new line inserted between lines |
| 15 | `15_join_two_lines` | Two lines joined into one |
| 16 | `16_split_line` | One line split into two |
| 17 | `17_multi_line_delete` | Multiple lines deleted in a row |
| 18 | `18_indent_change` | Only indentation changed |
| 19 | `19_trailing_whitespace` | Trailing whitespace change |
| 20 | `20_unicode` | Unicode chars (é, etc.) |
| 21 | `21_empty_old` | Empty old file, non-empty new |
| 22 | `22_empty_new` | Non-empty old, empty new |
| 23 | `23_identical_files` | Old and new are identical |
| 24 | `24_pure_add_at_eof` | Pure addition at EOF |
| 25 | `25_complex_mix` | Multiple changes interleaved |

are gitignored. They're generated by `run_minimal_tests.sh` for
debugging purposes.
